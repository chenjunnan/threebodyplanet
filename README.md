# 三体星（Three-Body Planet）— P0 四体科学模拟与 Web 控制台

当前开发方向：**M7.2 二维动态环境 + M7.3 简化大气、水循环和基础天气**。整体进度见
[总体路线图](docs/MASTER_ROADMAP.md)，冻结门限见
[集成实施规格](docs/P0-M72_M73_INTEGRATED_IMPLEMENTATION_SPEC.md)，科学层级见
[模型说明](docs/INTEGRATED_ENVIRONMENT_MODEL.md)。新环境归档与 IAS15/M3/M4/C0/C1 旧数据
分开，程序地形、气体先验、参数化风和天气事件都不是行星实测结论。

使用界面已拆为独立路由工作区：

| 工作区 | 用途 |
| --- | --- |
| `#/worlds` 创建世界 | 随机初态、候选选择、启动模拟 |
| `#/tasks` 任务与归档 | 进度、暂停/恢复、服务重启后恢复状态 |
| `#/orbit` 轨道观察 | WebGL/Canvas、真实采样回放、事件跳转 |
| `#/environment` 科学环境 | C0/C1基准、二维温度/水相/大气/风/降水、天气事件与M4 |
| `#/surface` 行星地表 | 程序地形、水盆、参数化大气/内热/纬度温度、地表观星 |
| `#/reports` 比较报告 | 多世界比较、原科学归档导出 |
| `#/settings` 高级配置 | 严格配置验证 |

一次只显示一个工作区；顶部统一选择运行和真实采样时间。切页保留当前归档，
后台任务继续，隐藏环境页面暂停图表重绘。浏览器刷新后需重新读取持久运行，不能把界面状态当作任务恢复。

建议首次选择 **60 秒演示 / 10 秒采样**：创建世界→任务进度→读取轨道→科学环境→行星地表。
0.4.3 世界会归档随机自转周期和**保留权重驱动的大气先验**；读取轨道后地表页可将其载入
表单。它使用质量、半径、自转和初始三恒星辐照形成 Jeans 参数代理，再叠加显式随机先验，
不是对大气存在的证明。点击地图选择地区，再计算以更新该地点三颗恒星的真实几何方位。
全球图绘制 10 个稀疏高程级别并标出当前观测点；水面使用高分辨率等面积盆地填充求解。
`planet-exploration-v9` 以全球等面积温度和饱和蒸气压守恒分配地表/大气水库存；高于水临界
温度时不保留液态地表水，并按水分压区分蒸汽大气与超临界含水包层。
大气可以继续使用显式摩尔分数，也可由场景 seed 与全球参考温度生成包含氮气、氧气、
二氧化碳、二氧化氮、甲烷、二氧化硫、水蒸气、氢气、氦气、氨气和兼容性氩气的可复现先验。
该先验只按一大气压相变温度平滑筛选可挥发性，不是化学平衡或大气形成史。三波段光学使用
各气体柱分子数、Rayleigh 散射和宽带吸收截面进行 Beer–Lambert 单路径消光；Web 同时显示
成分/柱密度诊断以及可拖动的地形、水体、大气和三星照明整体球体。
同一种子还生成环境约束的平原、山脊和断裂峡谷/陡崖；大气、自转和初始构型参考温度只调节
侵蚀与断裂先验强度，不声称反演真实板块历史，轨道播放也不会改变既有地貌。
地面镜头可沿已归档采样播放并锁定视野内恒星，恒星盘按真实角半径投影；地形垂直夸张、
HDR 和亮天空下隐藏装饰星空均为明确的纯视觉效果。
地质事件率未填写时概率为未知；可在高级区域先验填写事件定义，再输入如 `{"r12-c24":0.01}`。
下载的探索 JSON 包含输入假设、模型版本、轨道来源哈希及结果，不修改原科学归档。


这是一个基于 Python 3.11+ 的本地单用户科学模拟工程：生成可复现的**三颗恒星 + 一颗岩石行星**随机初始状态，经 S0 物理校验后，使用 REBOUND IAS15 进行真实牛顿四体积分，并在 Web 页面中观察轨道、辐射、温度、动力学事件与世界结局。也支持独立 CLI 实验和 JSON 科学归档。

P0-M2 使用 REBOUND IAS15 从原始 SI 笛卡尔状态进行真实 Newtonian 四体引力积分，记录
轨迹、运行期事件和守恒诊断。P0-M3 只读 M2 轨迹，计算三恒星总辐射、刚性行星自转、
C0 全球灰体热平衡和 C1 纬向扩散热模型。它不证明长期轨道稳定，也不提供天气或宜居性结论；
`hierarchical_orbit` 仍只是构造初始状态的近似方法。

M7.2-a 新增独立 `m72_three_reservoir_v1`：地表、浅层岩石和海洋混合层各自保存质量、
比热、总热容量和温度，按 SI 能量通量积分。恒定辐射与阶跃辐射用于标准基准；
`M5AOrbitForcing` 从验证后的完整 M5A 分段轨道计算三恒星辐照，并只在线性插值标量强迫。
检查点绑定配置与来源哈希，恢复是在边界重新启动 SciPy 求解器，不声称序列化内部 RK 阶段。
M3/C0/C1 仍是独立科学基准，旧归档不被覆盖。

M7.2-b 继续作为等面积多纬带三储热基准。新的 `integrated_environment_v1` 使用真实 M5A
三星笛卡尔轨道、自转轴/角速度和等面积二维网格计算昼夜、季节与多星照射，积分地表、浅层
岩石、海洋混合层和空气温度，并把水、冰、蒸汽、超临界不确定代理及硅酸盐岩浆分开报告。
M7.3 在同一守恒状态上增加气体柱、湿度、水循环、有界风和带迟滞天气事件；它是游戏需求
驱动的参数化模型，不是 GCM。分段检查点可安全恢复，三个环境 API 和 Web 图层只读取同一个
已提交结果。正式 P1 游戏客户端仍需等待该集成 PR 技术复审。

### G2.1 0.4.2 兼容基线与 M7.1 0.4.3 随机行星

`stochastic_conics/0.4.2` 继续作为冻结兼容基线；新的 Web 预设采用 `0.4.3`，随机生成
三颗0.3～8.0太阳质量的恒星。
各恒星根据**连续分段主序星质量—光度近似**确定玻尔总光度（0.43、2.0 M☉分界）
及简化质量—半径关系。三颗恒星的点源辐照按 `L/(4πr²)` 叠加；
它**不是**全谱、恒星风、内部聚变、年龄/金属丰度或恒星演化模型。
新的版本号是为了避免改变旧 `0.4.1` / `0.4.0` 配置与种子的科学生成结果。

每个新世界归档独立、可复现的**星体和行星自转轴、参考轨道倾角与旋转周期**。
M3纬度日照采用该世界行星的真实归档自转轴；恒星旋转仅作为运动学元数据，
因为各向同性点源模型中旋转不影响外部总辐照，且牛顿点质量模型不含扁率/自转四极矩。
C1仍是按经度平均的一维纬度热模型，不能解析日夜天气。0.4.3 额外从配置分布抽取
行星自转周期，轴仍为各向同性；使用新的独立 PCG64 子流，不改变 0.4.2 的轨道和自转结果。

0.4.3 可选大气由 `retention_weighted_prior_v1` 生成。氮、二氧化碳、氩、水汽和氧的
摩尔分数来自显式 Dirichlet 参数；氧的默认权重很低，不暗示生命。模型用瞬时辐照平衡温度、
旋转修正逃逸速度和平均分子质量计算 Jeans 参数代理，再用显式发生率抽样。该结果是参数先验，
不包含形成史、火山逸气、撞击剥蚀、恒星风或真实大气逃逸积分。

M7.1 地表模型按 36 个等面积纬带给出受热力/地转参考尺度约束的随机风速范围。
真空不生成风，范围不代表天气预报。地面天空使用 680/550/440 nm 三波段
Rayleigh/宽带吸收代理计算直达光衰减和相对天空颜色，再经 HDR 映射显示；不包含云、折射、
多次散射或逐线光谱。屏幕亮度不是 SI 辐亮度测量。

新Web轨道输出采样默认6小时（可调整为旧的1天），M3和M4最多支持50000个已验证轨道点。
高于限额的计算仍需增量热检查点架构；缩短输出间隔并不等同于提高IAS15内核精度。
C1日照采用与旧模型同为8点高斯求积的向量化计算，且使用数值回归测试对照原始逐带算法。

首次碰撞仍由REBOUND线段检测触发并**终止物理积分**。
恒星—恒星 `COLLISION` 事件额外记录简化的合并假设：质量、质心位置速度、
两星相对动能、假设松弛后主序星光度（仅限合并质量不超过8 M☉）
及行星在接触状态下的瞬时牛顿引力/玻尔辐照差值。
**这些都是诊断场景，绝非已积分的碰撞后轨迹、碰撞闪光或辐射能量预测。**
生成碰撞后的真实演化，需要单独的流体/质量损失/并合残骸与动态变体实现。

## M6.1：长期温度的分段检查点（首版）

Web的自动M3后处理现在可在 `runs/thermal_checkpoints/<run_id>/` 保存
C0/C1计算检查点。每段使用已验证的M5A物理采样时间，保存分段输出、
能量预算和校验哈希。温度派生中断或科学分析失败后，
点击「重新验证/分析科学数据」可在来源和参数不变时复用已完成段，
**无须重跑已经完成的IAS15轨道或此前已完成的C0/C1热段**。

检查点通过初态/物理/采样计划来源哈希、M3参数哈希、轨道时间网格哈希、
行星自转轴和连续分段哈希链绑定。变更输入配置或发现文件损坏时会拒绝复用，
不会静默混合来自不同世界的温度数据。已完成环境归档依然不可覆盖。

科学限制：此实现仅在真实轨道**输出时刻**恢复RK45/BDF，
没有序列化BDF内部多步状态；因此分段与一次性积分可有求解器允许范围内的
数值差异，不是逐位可重现。轨道源仍完整加载、最多50000点，
并未实现超上限的流式温度求解；大规模5年/10年性能基准仍需独立开展。
旧的M3归档继续可读，CLI原有无检查点调用方式未变。

## 安装与验证

使用 Conda（推荐）：

```bash
conda env create -f environment.yml
conda activate threebody-py311
pytest -q
ruff check .
```

如宿主机设置了其他 Python 版本的 `PYTHONPATH`（例如 ROS），建议为环境隔离该变量：

```bash
conda env config vars set -n threebody-py311 PYTHONPATH= PYTHONNOUSERSITE=1
conda deactivate
conda activate threebody-py311
```

若当前 shell 已经继承 ROS 的 pytest 自动插件且无法立即重启环境，可临时使用：

```bash
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 pytest -q
```

也可以使用标准虚拟环境或已有 Python 3.11 环境：

```bash
python -m pip install -e '.[dev,physics,viz]'
ruff check .
pytest -q
threebody --help
```

项目要求 Python 3.11 或更新版本。核心依赖 NumPy、SciPy、Pydantic v2 和 PyYAML；
M2 的 `physics` extra 安装 REBOUND 4.x。不依赖外部数据库或前端框架；Web 功能使用项目内置的本地 HTTP 服务及后台计算线程，不应暴露到公网。
轨道查看器是独立的 `viz` extra；需要时使用
`python -m pip install -e '.[dev,physics,viz]'` 安装 Plotly。

## 使用

验证配置并查看其稳定 SHA-256：

```bash
threebody config validate configs/example_experiment.yaml
```

保存完整解析后的配置：

```bash
threebody config resolve configs/example_experiment.yaml --out /tmp/resolved.json
```

生成并筛选十个候选初态：

```bash
threebody world generate \
  --config configs/example_experiment.yaml \
  --count 10 \
  --out-dir runs/sample
```

输出目录结构：

```text
runs/sample/
  resolved_config.json
  manifest.json
  summary.json
  candidates/
    000000.initial.json
    000000.screening.json
    ...
```

`manifest.json` 记录完整解析配置、配置哈希、Python/NumPy/生成器/RNG/常数集版本。
`summary.json` 包含 `total`、`accepted`、`rejected`、`invalid`、逐规则统计和每个候选的
决策。所有 JSON 都拒绝 NaN 与 Infinity，并通过临时文件加原子替换写入。

## G2 全随机四体初态

G2 新增独立的 `stochastic_conics/0.4.0` 生成器；旧 `cartesian` 和
`hierarchical_orbit/0.1.0` 的算法、解析结果和配置哈希保持不变。生成一批宽分布探索初态：

```bash
threebody world generate \
  --config configs/g2_chaotic_worlds.yaml \
  --count 100 \
  --out-dir runs/g2-chaotic
```

每个成功候选除原有 `.initial.json` 和 `.screening.json` 外，还会写出
`.generation_metadata.json`，其中记录质量/密度抽样、随机宿主、三个构造圆锥、三维方向、
真近点角、速度扰动向量和随机子流协议。`summary.json` 的 `g2_generation` 汇总宿主、偏心率、
圆锥类型、瞬时距离、速度、失败原因码和初始接触计数。

生成器允许椭圆和双曲初态，不施加层级比、长期生存、稳定性或宜居性默认筛选。`e=1` 的
抛物线模式在 0.4.0 中明确拒绝；双曲真近点角只从有效开区间抽样。若球形天体在 `t=0`
接触或重叠，会额外归档 `.initial_outcome.json`，标记为未执行积分的终止结局；M2 输入 Guard
仍会拒绝把它交给 IAS15。研究预置可保留并报告这类游戏结局，不代表点质量积分对接触后状态
有效。

### G2.1 可选初态边界

`stochastic_conics/0.4.1` 增加独立、严格版本化的生成后约束。它不会改变 0.4.0 配置、
哈希或随机结果，也不会裁切速度：

```bash
threebody world generate \
  --config configs/g21_bounded_worlds.yaml \
  --count 100 \
  --out-dir runs/g21-bounded
```

`mode: bounded` 在速度 kick 和最终质心归一后检查行星到三颗恒星的真实瞬时距离、三对恒星
距离、行星相对恒星系统质心速度，以及所选宿主二体或三恒星冻结组合势的逃逸速度代理。
不满足条件时使用有上限的确定性拒绝采样；每次尝试及原因均归档，耗尽后报告
`GENERATION_CONSTRAINT_EXHAUSTED`。`mode: unrestricted` 保留首个完整混沌样本，不应用这些
偏好。逃逸速度比例只是 `t=0` 指标，不证明未来不会飞离；碰撞和不稳定演化仍由 M2 决定。

## M2 四体轨道演进

先生成初态，再选择一个候选运行模拟：

```bash
threebody world simulate \
  --initial runs/sample/candidates/000000.initial.json \
  --config configs/m2_ias15.yaml \
  --out-dir runs/sample/simulations/000000
```

模拟目录采用临时目录完成后原子提交，包含：

```text
trajectory.jsonl                    # 严格递增时间的流式轨迹样本
events.json                         # 碰撞、近距离遭遇、逃逸候选
diagnostics.json                    # 守恒误差与每对天体最小已观察距离
resolved_simulation_config.json     # 完整 M2 数值配置
simulation_manifest.json            # 输入哈希、版本、状态和产物引用
```

IAS15 显式使用 SI 引力常数 `G=6.67430e-11`，不进行 `move_to_com`，不启用引力软化。
求解器输入 Guard 始终启用，独立于 S0/S1 筛选配置。物理接触使用 REBOUND swept-line
碰撞检测并默认终止，碰撞双方直接来自 REBOUND 回调的粒子索引，不从终止状态猜测；
碰撞时间是求解器内步检测精度，不声称无限精确。近接检测不改变
动力学；近接距离只是在 IAS15 内步端点观察到的最小值，不是连续轨道的严格数学极小值。
`ESCAPE_CANDIDATE` 使用边界、向外速度、近似比能和持续时间，只是启发式分类，
不等同于永久逃逸证明。

## M7.2/M7.3 长期动态环境

在一个已完成的 M5A 分段轨道上创建或恢复独立环境归档：

```bash
threebody world environment-long \
  --run runs/m72-m73-five-year \
  --config configs/m72_m73_five_year_reduced.yaml \
  --out-dir runs/integrated_environments/m72-m73-five-year
```

对含 G2/M7.1 `atmosphere_hypothesis` 的世界，可增加
`--atmosphere-from-world-prior`，把已归档随机先验严格解析为柱库存；它仍是先验，不是观测。
`--max-segments` 可在安全段边界暂停，下次使用完全相同命令恢复。归档完成后启动 Web 服务，
`#/environment` 可显示二维温度、水/冰/熔融、压强、湿度、风、降水及事件时间轴。

客户端稳定接口为：

```text
GET /api/v1/environment/{run_id}/point?t_s=&latitude_deg=&longitude_deg=
GET /api/v1/environment/{run_id}/series?latitude_deg=&longitude_deg=&max_points=
GET /api/v1/environment/{run_id}/tiles/{time_index}/{level}
```

三类数据来自同一不可变归档并返回 SI 单位、字段质量与配置/来源/结果 SHA-256。瓦片高层级
只是明确标识的显示聚合，不重新求解物理；浏览器播放速度不会改变环境积分速度。

## VIS1 四体轨道查看器

对已有 M2 归档生成可离线打开的交互式 3D HTML：

```bash
threebody viz trajectory \
  --run runs/sample/simulations/000000 \
  --out runs/sample/simulations/000000/trajectory.html
```

默认以 AU 显示质心惯性系坐标，并内嵌 Plotly JavaScript。可使用 `--units m` 保留米，
`--frame-cap` 限制动画帧，`--max-input-samples` 限制读取规模，或用 `--cdn` 生成依赖网络的
较小文件。输出文件默认不覆盖；只有显式 `--overwrite` 才会替换。

查看器严格读取现有 `TrajectorySample`、`SimulationEvent` 和 `IntegrationResult`，不会修改、
补算或重新积分轨道。事件没有原生坐标，因此标记位置是依据 `event.body_ids` 在相邻归档采样
间做的线性显示估算，不是精确碰撞位置。天体点大小是屏幕符号尺寸，不代表物理半径；动画
播放速度也不代表物理时间流速。`STOPPED`/`FAILED` 若有完整采样仍可显示，但页面会醒目标为
部分轨迹。

## VIS2 多物理场联动观察器

用同一模拟时间轴联动 M2 四体轨道和 M3 辐射/C0/C1 数据：

```bash
threebody viz dashboard \
  --m2-run runs/sample/simulations/000000 \
  --m3-run runs/sample/thermal/000000 \
  --out runs/sample/dashboard.html
```

可选 `--m4-run` 加载经来源哈希验证的世界结局时间线；`--units au|m` 控制轨道单位，
`--frame-cap` 限制显示帧。HTML 默认内嵌 Plotly，可离线打开。桌面布局包含 3D 四体轨道、
三颗恒星独立及总辐照度、C0 温度和 C1 纬度热图；移动端自动堆叠。播放倍率只表示视觉速度。

权威时间范围严格取 M2/M3 重叠区间。轨道与温度的线性插值只用于显示，不是新的 N 体积分
或热求解；不在数据末端外推。碰撞归档在最后科学样本停止，逃逸候选若仍有 M2/M3 数据则
继续播放。质心/行星相对相机只是坐标显示变换。事件文字使用安全 JSON 和 DOM `textContent`，
不会作为 HTML 执行。原 `threebody viz trajectory` 命令保持不变。

```bash

  --config configs/m3_thermal.yaml \

```

归档包含：

```text
stellar_flux.jsonl                 # 每颗恒星距离、方向、中心辐照度与三源总和
```

## M5A 长期模拟契约

M5A 新增严格的 `0.6.0` 长期运行契约和示例配置 `configs/m5a_long_run.yaml`，定义统一物理
时钟、不可变分段索引、检查点/运行 manifest、三类兼容哈希以及任务状态机。M5A-02 提供
程序化 REBOUND 二进制检查点保存/验证/加载和 observer/诊断状态恢复；M5A-03/04 基础层
提供原子分段提交、哈希链、显式单写锁、孤儿发现和幂等索引修复。M5A-05/06 提供真实
分段 IAS15 runner、段中物理时间检查点、保留策略、流式 reader 以及启动/恢复/验证 CLI。

```bash
threebody world simulate-long \
  --initial runs/sample/candidates/000000.initial.json \
  --config configs/m5a_long_run.yaml \
  --out-dir runs/sample/long/000000
threebody world resume --run runs/sample/long/000000 --max-wall-seconds 3600
threebody world verify-long-run --run runs/sample/long/000000
threebody world checkpoint inspect --run runs/sample/long/000000
```

`resume` 只接受安全暂停或进程中断后仍为 `RUNNING` 的归档；碰撞、完成、失败和取消终态不能恢复。墙钟限额只在安全分段边界形成 `PAUSED`。Web 现已提供本地单用户后台 Worker 与真实的启动、暂停、恢复及取消请求，但暂停/取消须等当前物理分段提交完成后才生效，不能将界面播放暂停与物理积分暂停混淆。

长期归档不会自动抢占或删除已有写锁，也不会自动删除临时孤儿目录。恢复过程只登记已经
原子改名并通过完整哈希链验证的分段；未知目录、计划外分段、缺失文件、非有限 JSON 和
任何哈希不一致都会停止恢复。已提交分段不可重新打开或覆盖。

权威物理时间始终是 REBOUND 的绝对 SI 秒 `simulation.t`。输出目标由全局整数索引计算，
分段后不归零；墙钟配额、浏览器回放速度和行星自转周期均不是积分时间。首段拥有全局起点
样本，后续段采用左开右闭覆盖，避免恢复后重复边界样本。

## Web 控制台使用说明（P0 / M5B）

Web 是**本机单用户科学实验控制台**，支持随机生成四体世界、选择候选、设定物理演化时长、真实 IAS15 积分、鼠标交互式三维轨道观察、自动环境分析及多世界报告比较。无需单独安装 JavaScript 构建工具或前端服务器。

### 1. 启动与打开网页

在项目根目录执行以下命令；如未安装环境，请先完成上面的「安装与验证」：

```bash
python -m pip install -e '.[dev,physics,viz]'
mkdir -p runs
threebody web serve --artifact-root runs --host 127.0.0.1 --port 8765
```

使用浏览器打开 **http://127.0.0.1:8765**。保持运行该命令的终端打开，按 `Ctrl+C` 关闭服务。所有世界、模拟归档、派生环境数据与结局报告默认保存在 `runs/` 下；可用 `--artifact-root` 选择独立数据目录。端口冲突时更改 `--port`，并使用新端口访问。

**安全提示：** 该服务没有公网用户认证，仅允许绑定本机回环地址（`127.0.0.1`）；不要使用端口转发、反向代理等方式将其公开给其他设备或互联网。

### 2. 随机生成世界并选择候选

在页面顶部「**创建随机三恒星世界**」区域：

1. 设置**随机种子**和**候选数量**（1–20 个）。相同完整配置、种子、候选序号和运行环境下，可复现相应初态。
2. 选择 `bounded`（限制初始速度、距离和瞬时逃逸速度代理）或 `unrestricted`（保留随机生成的混沌初态）。
3. 可编辑行星初始速度上限（km/s）、最近恒星距离上限（AU）、逃逸速度代理比例以及行星偏心率最大值；高级用户展开**完整 G2.1 JSON**继续编辑其他科学参数。
4. 点击「**随机生成候选**」，在候选卡片中选择标记为「可积分」的世界。初始接触、生成失败或未通过强制 S0 校验的候选会显示原因，但不能提交给 IAS15 继续演化。

这些约束只作用于**初始时刻**，不保证行星长期束缚、轨道稳定或适宜生命。三颗恒星和行星是否后续碰撞、近距离遭遇或逃逸候选，取决于真实四体积分结果。

### 3. 设定时长，运行真实模拟

在同一区域选择「**模拟时长**」「**输出采样间隔**」和唯一的「**运行ID**」，再点击「**启动选中世界的真实模拟**」。

| 参数 | 含义 |
| --- | --- |
| 模拟时长 | 物理时间跨度；提供 60 秒演示、1 天、7 天、1 儒略年、5 年和 10 年预设，实际以 SI 秒计算 |
| 输出采样间隔 | 轨道归档写入相邻采样点的间隔，不是 IAS15 自适应积分步长 |
| 运行ID | 当前归档根目录中的唯一标识；不能覆盖既有运行 |

首次上手建议选择**60 秒演示 / 10 秒输出间隔**验证全链路，再尝试长时模拟。更长模拟会消耗更多计算时间和磁盘空间；输出过密可能达到每次运行的资源预算。为后续温度分析，通常建议输出间隔**不大于 86,400 SI 秒**，但实际计算还受物理过程变化速度和配置限制。

Web 后台通过真实 REBOUND IAS15 分段积分，并返回「排队 / 运行中 / 已完成 / 碰撞终止」等状态；提交任务成功（HTTP 202）**不表示物理计算已经完成**。发生碰撞后停止物理演化，不推演未建模的碰撞后轨迹。

### 4. 控制任务与恢复计算

在「**真实长期模拟任务**」区域，可以对已有运行ID执行：

- **请求暂停 / 请求取消**：等待当前安全分段完成后生效，不会强行中断 IAS15 内部积分或正在写入的检查点。
- **恢复模拟**：仅适用于持久归档为 `PAUSED` 或经恢复检查允许继续的中断 `RUNNING`；已完成、碰撞及其他终态不得继续。
- **读取持久运行状态**：Web 服务重启后，重新输入原运行ID，从实际 M5A 归档读取状态。
- **重新验证/分析科学数据**：对已完成或碰撞终止的物理归档，重新核验并按适用范围运行 M3/M4 派生分析。

**区别三个时钟：** REBOUND 权威物理时钟（SI 秒）≠ 输出采样间隔 ≠ 浏览器轨迹播放速度。界面暂停播放不会暂停物理计算。Web 关闭或异常退出后不保证自动续算；需要核验持久状态，再显式恢复。恢复依赖真正的 REBOUND 二进制检查点和单写者锁，而不是由画面坐标重建积分器。

### M6.3-c：天体选择、聚焦与事件物理时间同步

实验性WebGL2观察器现在支持点击渲染的恒星或行星球点、选择天体、
聚焦/重置相机；相机始终根据**选中M5A真实输出时刻的实际天体位置**进行
视觉变换，不写回积分结果。旧Canvas观察器继续支持天体列表、
质心惯性坐标、聚焦和重置；WebGL不可用时保持同一组科学数据。

新增只读 `GET /api/v1/runs/{run_id}/bodies`：由已验证的
M5A初始状态和来源SHA256构建，返回三恒星/行星的质量、半径、
可用的初态光度、自转速度及自转轴。属性面板明确区分
“初态属性”与“当前真实轨道位置”，**不会把初态恒星半径冒充碰撞后残骸**。
事件跳转只选取最近的真实轨道采样并显示与事件时间的偏差；
不会把显示插值、点击拾取或动画时间当作真实轨道状态。

### M6.3-a/b：实验性WebGL2观察器

现有轨道观察区新增「实验性WebGL2三维观察」开关，默认为关闭。
启用后使用同一组已验证的M5A输出采样点，在GPU进行三维旋转和深度测试。
浏览器不支持WebGL2或发生上下文丢失时自动回退到原Canvas观察器；
任何情况下都不会从渲染器生成新的物理轨道、辐照或温度数据。

只读科学适配器拒绝错误运行ID、世界ID、非SI单位、非法身体位置、异常时间网格、
显示采样语义不明及M3跨世界数据。3D可视化对SI坐标做减原点、缩放后才送入
GPU浮点缓冲；显示半径/亮度是可视化而非科学测量。
当前实验原型只包含四体位置与轨道线，不含真实半径材质、恒星光谱、C1球面温度
或碰撞后的虚构续算。仍建议将Canvas作为默认稳定模式。

### 5. 观察四体三维轨道和世界演化

选择运行ID，进入「**长期轨道观察**」区域；模拟完成后会自动尝试载入对应轨道，也可手动点击「**读取真实轨迹**」。

| 操作 | 作用 |
| --- | --- |
| 在轨道画布上按住鼠标左键拖动 | 旋转三维视角 |
| 在画布上滚动鼠标滚轮 | 缩放视角 |
| 「视角向左/向右/抬高/降低」 | 使用按钮调整相机方向 |
| 拖动观察时间滑块 | 跳转到已记录的 SI 物理时间 |
| 「播放 / 暂停播放」 | 仅控制历史轨迹可视化速度 |
| 「事件跳转」 | 定位碰撞、近接或逃逸候选等归档事件；显示事件与最近采样点的时间差 |
| 开始/结束时间及最多采样数 | 读取指定真实时间范围；单次轨道显示最多 2000 个采样点 |

四颗天体的显示来自原始三维坐标的**可旋转二维画布投影**，并非 WebGL 实体渲染。轨迹不补算未来，不在科学数据范围外外推；屏幕中的天体符号大小也不代表真实半径。

真实模拟完成后，后台自动尝试计算以下科学数据：

- **恒星辐射**：三颗恒星独立辐照度和总辐照度曲线。
- **C0 全球温度**：灰体能量平衡模型的全球温度变化。
- **C1 纬度热图**：纬向热扩散模型随时间的变化。
- **M4 世界结局**：动力学事件、环境暴露和分类，使用与 M5A/M3 相匹配的来源哈希。

轨道、辐射、温度和事件共用物理时间语义。**没有得到相应数据时显示缺失，而不是推测温度或宣称宜居。** `ESCAPE_CANDIDATE` 仅为逃逸候选，不是永久逃逸证明。

### 6. 多世界比较与导出科学报告

在「**多世界科学比较与导出**」区域，输入 1–8 个用逗号分隔的已归档运行ID，例如 `world-001,world-002`。点击「**比较世界**」，查看各世界的动力学状态、已计算物理时间、轨迹采样量及结局分类；点击「**导出JSON科学报告**」保存科学记录。

比较与报告会先核验原始 M5A 分段归档、可用的 M3 温度产物及 M4 分类产物的来源和哈希。温度/分类尚未生成时会明确显示缺失，报告包含用于追溯的标识和内容摘要。运行ID必须不同，损坏的科学归档会被拒绝。

### 7. 文件目录、接口与故障排查

典型的 `--artifact-root runs` 结构：

```text
runs/
  worldsets/<batch_id>/             # 随机世界候选及初态来源记录
  <run_id>/                         # M5A 轨道、检查点、事件及任务清单
  environments/<run_id>/            # 自动派生的 M3 辐射/C0/C1（可用时）
  outcomes/<run_id>/                # 自动派生的 M4 世界分类（可用时）
```

关键API可在浏览器打开 `http://127.0.0.1:8765/api/v1/openapi.json` 查看；健康检查是 `/api/v1/health`。模拟归档可通过以下命令独立验证：

```bash
threebody world verify-long-run --run runs/<run_id>
```

常见情况：

- **没有可选候选**：当前随机种子或约束使候选全部接触、违反S0或生成失败；适当放宽初态约束或换种子，不必修改引力物理。
- **运行ID已存在**：重新指定唯一ID；程序不会覆盖已提交科学归档。
- **世界运行完成但温度未出现**：科学派生与物理积分分开进行；超过**50000个轨道采样点**、采样时间间隔超过30天、发生碰撞或派生失败时，热数据可能不可用。可在任务状态中查看`analysis_status`和`analysis_error`，或使用「重新验证/分析科学数据」。已有5天/30天采样的已完成运行可直接重新分析，无须重新运行IAS15，但结果将明确标记为低置信度近似。
- **页面重启后任务状态不显示**：在任务区域输入原运行ID并点击「读取持久运行状态」；不应创建同名新运行替代恢复。
- **轨道显示卡顿**：缩小查询时间范围或降低「最多采样」；这只影响显示帧数，不修改物理模拟。
- **跨设备打不开网页**：这是仅限本机的P0安全约束，并非公网Web服务。

**P0科学边界：** 当前M3长期派生面向已完成、未碰撞且不超过50000个输出采样点的运行；>1天且不超过30天的稀疏输出允许生成标注质量的温度近似，但无法重建两点之间的高速近距离经过/恒星辐照峰值，此类温度**不得用于M4环境科学分类**。不能承诺任意十年配置都自动得到完整温度历史。C0/C1 是简化参考热模型，不包含真实天气、海洋、复杂大气或生命演化；P0不支持多人在线、碰撞后物理或已证明的长期轨道稳定。

工程CI另设独立浏览器测试工作流 `.github/workflows/browser.yml`。

## 配置与筛选语义

配置合并优先级为内置预置配置，然后是实验 YAML 的显式覆盖。未知字段、未知规则 ID、
未知预置、非法参数和数值字符串都会被拒绝；YAML 使用 `safe_load`，不执行表达式或 Python。

预置模式：

- `strict`：五条 S1 规则启用且失败会拒绝候选。
- `research`：保留异常候选并报告；密度规则默认关闭。
- `raw`：关闭全部 S1，结果标记为 `scientific_validity=unverified`。

无论预置如何，S0 始终检查 schema、有限数值、SI 单位、坐标向量、规范 ID、唯一性以及
恰好三颗恒星和一颗行星。S1 包含：正质量、正半径、密度边界、初始表面间隙和质心误差。
禁用规则报告 `SKIP`；规则依赖或求值错误报告 `ERROR` 并使候选成为 `INVALID`。

## 可复现性

每个候选使用独立的 `PCG64(SeedSequence([seed, candidate_index, stream_id]))` 随机流。
因此候选生成顺序、其他候选失败以及筛选规则开关不会改变某个候选的天体参数。同一项目/
生成器/NumPy 版本、完整配置、seed 和 candidate index 可复现同一初态；不承诺跨运行时版本
逐位一致。

### M6.3-d：表面材质与 C1 温度球面

观察区提供三套恒星颗粒材质和一套岩石表面材质（`surface-v1`），由本地程序生成，
无外部图片/CDN。开关可在 Canvas/WebGL 轨道中启用或关闭增强球面符号。
固定暖金、赤橙、蓝白配色、纹理与明暗都是视觉示意，不是观测光谱、真实地形、
已验证昼夜或物理半径；它们不改变天体位置、辐照、温度及碰撞判据。
轨道符号使用球面投影贴图，不是具有物理半径的实体网格。

C1 温度球面位于热模型区，使用行星局部坐标、北纬朝上的正交球面投影。
它不是轨道中的自转轴姿态展示。每条温度带的边界严格等分 `sin(latitude)`，
无经度变化；颜色与当前窗口的 C1 时空热图使用相同的蓝→红相对色标。
球面不叠加装饰材质或光照明暗，以保留温度颜色语义。

选择轨道采样时，球面显示时间范围内最近的真实 M3 温度采样，注明 SI 秒、
时间差、采样质量和警告；不插值、不外推。悬停读取纬带中心与 K/°C 数值。
色标在已加载窗口内固定，微小温差会明确提示；等温数据统一蓝色。
缺失、无效、越界或读取失败时清空温度球面，不复用上一世界的数据。

浏览器测试可复用系统 Chromium：
`THREEBODY_TEST_CHROMIUM=/usr/bin/chromium pytest -q tests/test_m5b_browser.py`。

### 观察器控制兼容性

Canvas 和 WebGL 均可点击天体选择，并沿用已验证天体属性面板和事件时间联动。
画布获得焦点后，方向键旋转、`+` / `-` 缩放、`Home` 重置、空格播放或暂停。
切换渲染器保留相机角度、缩放、选择和观察时间；WebGL 上下文丢失退回 Canvas。
回放只遍历已下载的真实采样，不推进物理积分。反复切换会清理旧监听器，避免重复拖动。

### M6.3-e：事件视觉与观察器性能基准

事件选择框及「上一个 / 下一个事件」跳转到当前窗口内最近的真实轨道采样，
并暂停历史回放。粉色圆环表示碰撞涉及天体，青色圆环表示其他选中事件涉及天体。
标记只在该事件对应的采样显示，可用开关关闭；标记位置不是精确事件位置，
页面同时给出真实事件时间、轨道采样时间和两者偏差。窗口外事件禁用跳转，
不会推算位置。没有闪烁、爆炸能量或碰撞后的合并轨迹。

碰撞终止的归档显示持续提示，轨道回放停在最后一条真实采样；客户端拒绝
包含碰撞后轨道点的事件/轨迹组合。读取失败会清空旧事件及标记。
近接不改变轨道，`ESCAPE_CANDIDATE` 仍只是候选，不证明永久逃逸。

可重复运行四天体、2000 采样点的观察器图形基准（需 Playwright/Chromium）：

```bash
THREEBODY_TEST_CHROMIUM=/usr/bin/chromium python scripts/m63_observer_benchmark.py \
  --frames 120 --out /tmp/m63-observer-new.json
```

脚本拒绝覆盖报告，使用明确标注的图形夹具，不执行或声称完成科学积分。
分别测量 Canvas/WebGL 静态、回放和 WebGL 聚焦回放；先预热再记录绘制耗时、
浏览器帧间隔中位数/p95/最大值，并检查源坐标不变和 WebGL 错误。
Canvas 绘制耗时仅为 API 提交，WebGL 包含 `gl.finish()`；帧间隔单独反映调度与绘制。
不包括热面板、科学计算或 API 查询耗时，不保证任意硬件达到 60 FPS。
浏览器 CI 会运行短基准并上传 JSON，不以不稳定的机器性能阈值替代功能验收。
