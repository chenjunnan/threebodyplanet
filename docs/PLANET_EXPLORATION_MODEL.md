# 参数化岩石行星探索 v2

这是一套可复现参考实验，不是完整地球系统或灾害预测模型。现有 IAS15/M3/M4 归档不变。
入口：`POST /api/v1/planet-scenarios`，输入 `run_id` 与 `parameters`；只读，不落盘改写科学数据。
请求必须使用一个精确已提交采样。碰撞时刻及其后的地表场景禁止；不外推未来。

## 输入与可追溯性

源自哈希验证归档：三颗恒星的位置和初态光度、行星位置、质量/半径、自转元数据。
用户输入：地形种子/幅度/形状指数、表面水质量、大气质量/平均摩尔质量、
氧/水汽/二氧化碳/氩摩尔分数（余量为氮）、
反照率、发射率、灰色光学厚度、内核温度、地幔厚度/导热率、地点、经度初相位、
灾害时间窗和区域发生率。归档缺少自转参数时必须显式提供，不默认为地球一天。

导出包含版本、解析参数、初态/物理/采样 SHA-256、源时刻以及场景哈希。
场景哈希包含模型版本、源和参数。修改采样或输入会清空旧场景，不能把两次运行混在一起。

## 重力与大气

- 球形重力 `g=GM/R²`，自转参数 `q=ω²R/g`，赤道有效重力参考值 `g(1−q)`。
- 限制 `q<0.1`，本模型不求旋转流体的真实形变；不从自转生成板块山脉。
- 薄大气球面平均静水压力 `p=g M_atm/(4πR²)`。
- 等温尺度高度 `H=R_gas T/(μ g)`，它不是具有硬边界的大气总厚度。
- 氧/水汽分压为总压乘用户提供的摩尔分数；不推断生物、氧源或水汽循环。
- 0.4.3 世界可提供带 `is_observation=false` 的大气先验；载入后仍作为显式场景参数，
  不会改写 M3 或把先验升级为归档事实。
- 气体+表面水库存不得超过行星质量的5%，地形幅度不超过半径的5%。

## 内热与温度

在36条等面积纬带上，三颗恒星各自日平均入射为：

`F = S/π [H0 sinφ sinδ + cosφ cosδ sinH0]`，`H0=acos(clamp(−tanφ tanδ))`。

`S=L/(4πr²)`，赤纬 δ 来自真实恒星方向与行星自转轴。处理极昼/极夜。
静态平衡由二分求解：

`εσT⁴/(1+0.75τ) = (1−A) ΣF + max(0, k(Tcore−T)/d)`。

这不是内部热演化：没有年龄、放射性冷却、热对流和潮汐热史。
也不是 M3 C1 的新实现：没有经向热输送、海流、真实大气光谱或天气；τ 是显式假设，
并不由大气质量自动推出。赤道/两极数值采用同一个平衡方程。
日平均需要快速自转/热平均条件；缓慢或静止行星的局地瞬态不由该模型解释。

地转尺度 `U≈(R_gas/μ)|∂T/∂y|/|2ωsinφ|`，隐含一个尺度高度的对数压力对比。
赤道或地转尺度失效时保留热力速度参考。每个纬带用独立 PCG64 子流在显式范围系数中
抽取上下界，并限制在0.3倍参考声速内。真空返回 null。它是带种子的参数范围，不是
地表风速预测；不模拟天气、环流或风成地貌，也不宣称按自转速度唯一确定风速。

## 地形、山地、水盆

十二个球面三维噪声模态由确定性种子生成，频率/相位/方向与振幅随场景导出；
形状指数增强中尺度山脊，但绝对高度仍受显式起伏和半径5%上限约束。
这是连续程序地形，不是板块求解。24×48等面积网格用于区域统计；地表镜头用相同模态重建。
水盆面由 `Σ max(0,h_sea−h_i)·area_i = M_water/1000` 求解，保证离散假设水体体积守恒。
假设海平面不是水循环结果。水相代理只在简化温压条件内使用：低于273.16 K标冰，
273.16～373.15 K使用常潜热饱和压力近似，过热时标未知；未包含盐度和蒸发反馈。
不满足可视水相条件时不绘成蓝色海洋。全球地图叠加20～30个等间隔高程级别，默认24；
这些等高线只描述同一程序场。地形高度、海拔与区域温度都标为参数实验。

## 地质事件概率

每个区域 ID 为 `r0-c0` 至 `r23-c47`。用户提供该区域每年的某类事件率 λ，
必须同时提供清晰的事件定义（例如震级阈值），给定时间窗 Δt，返回 `P(N≥1)=1−exp(−λΔt)`。事件定义和空间尺度必须由使用者一致指定。
没有率就返回 null；零只有在显式输入率为零时成立。
这只是平稳泊松条件概率，不从质量、山脉或颜色伪造地震、火山、滑坡的真实概率。

## 地表观测

经度零点的惯性方向由确定性基向量与显式初相位定义，旋转角是 `ω·t_s+phase`。
表面位置加地形/水面及眼高，结合真实采样星体位置计算几何方位与高度。播放只切换至
M5A API 返回的精确采样，可锁定一颗地平线上方恒星；不在采样之间插值或推进积分器。

可见光代理在680/550/440 nm计算压力和成分加权 Rayleigh 光学厚度，以及水汽、氧和
二氧化碳的宽带吸收项。Kasten–Young 空气质量给出各恒星三波段透射和地表直达辐照代理；
恒星本征三色由归档光度/半径得到的有效温度黑体代理形成。WebGL按这些直达光对地形法线
照明，并对散射天空与恒星做 HDR 色调映射。屏幕RGB不是SI辐亮度；无云、气溶胶、折射、
多次散射、逐线光谱、地形遮挡或真实星表，不表示真实摄影。

## 验证范围

解析灰体极限、内热能量平衡、S/4全局辐照积分、压力库存比例、种子重复性、
0.4.2冻结哈希、0.4.3自转/大气多样性、三波段消光、空气质量极限、风范围和等高线级数、
水体体积守恒、先验缺失、坏参数/API校验、真实轨道来源和浏览器场景导出均需测试。
这些测试证明实现满足所声明近似，不证明模型足以解释任意真实行星。
