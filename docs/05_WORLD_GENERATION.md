# 05 — 初态生成器算法与边界

## 1. 输入输出

输入：`ResolvedExperimentConfig`、`seed`、`candidate_index`。输出：`WorldInitialState`（生成器不筛选，不执行模拟）。当前固定产生三颗恒星和一颗岩石行星。

## 2. 基本星体参数

本阶段使用简单而明示的**参数采样范围**（不是完整恒星形成/演化模型）：

- 恒星质量以太阳质量为归一单位采样，然后乘 `M_sun_kg` 转为kg；半径可使用配置的主序星近似关系生成，并在 `physical_profile_id` 标注 `approx_main_sequence_v1`。
- 行星质量以地球质量为归一单位采样；平均密度从可配置岩质范围采样；通过 `R = (3M/(4πρ))^(1/3)` 计算半径。该关系是几何与平均密度关系，**不是完整质量-半径结构模型**。
- 恒星光度可按明确标记的近似质量-光度函数估算，但当前M1不做辐射积分；如果无法合理配置模型，可只保存mass/radius并不输出light output。
- 所有取样范围、概率分布、近似公式必须在配置或生成器版本中明确，不要在代码中藏未说明魔法数。

## 3. `cartesian` 生成器

- 从配置中的特征长度scale_m、质量标度，生成非共线的初始位置。
- 速度按无量纲倍率× `sqrt(G*M_total/length_scale)` 取样；可设 `velocity_scale_factor`。
- 移除系统质心位置、系统质心速度；保证输出为 `BARYCENTRIC_INERTIAL`。
- 对重复/完全共位天体：允许生成器输出候选，由初始重叠规则筛选；但不能产生NaN或Infinity。

## 4. `hierarchical_orbit` 生成器

建议M1最小版本：

1. 生成S1/S2的相对双体圆轨道（或给定离心率），在平面或随机轨道平面中计算相对位置和相对速度。
2. 将第三恒星放到相对于内双星质心的外层近似两体轨道；对第三恒星和内双星施加相互的质心速度修正。
3. 在一颗恒星附近或整个恒星系统附近生成行星近似两体初始轨道（由配置指定 `planet_orbit_host`）。
4. 转换到整个四体的系统质心位置和速度。
5. 明确：前述叠加只是**近似初态构造**，不表示将来的轨道稳定，也不能当成四体精确解。

若实现复杂离心轨道与轨道旋转显著增加风险，M1优先支持圆轨道加参数化倾角；把更完整的轨道要素放入后续增强。**不允许为了显得完成而写随机坐标冒充层级轨道。**

## 5. 可重复候选流

- 推荐SeedSequence创建分支流：`candidate_index`与用途编号分离。
- 某候选失败，下一候选生成不受影响；即使筛选规则开关变化，候选的**初态参数**也应不变（假设生成器配置不变）。
- 记录`generator_id`、`generator_version`、`rng_algorithm`、`rng_version`。

## 6. 输出基本诊断

- 总质量、质心位置/速度、最小表面距离、初始相对速度尺度。
- 不计算“轨道周期”作为稳定系统的结论；可以输出构造时采用的**两体近似周期**并明确注明估计性质。
- 如质量/半径不合理且启用了report-only规则，输出仍须可序列化，报告其科学有效性未知或失败。

## 7. 最低配置参数建议

- `stellar_mass_solar`: `[0.6, 1.5]`
- `planet_mass_earth`: `[0.3, 3.0]`
- `planet_density_kg_m3`: `[3500, 7000]`
- `characteristic_length_m`: `1.495978707e11`（1 AU作为长度尺度）
- `inner_orbit_radius_m`: `1.495978707e11`
- `outer_orbit_radius_m`: `1.495978707e12`
- `planet_orbit_radius_m`: `1.495978707e11`

以上仅为工程**示例默认值**，并非经过三恒星可探索性验证的参数区间。世界生成多样性需要M2预演后统计决定。
