# integrated_environment_v1 科学模型说明

`integrated_environment_v1 / schema 1.0.0` 是 M7.2-c/d 与 M7.3 的游戏需求驱动环境模型。
它读取一个已完成且通过哈希验证的 M5A 四体归档，在统一 SI 物理时间上生成独立、不可变的
派生归档；不修改 M5A、M3/C1、M4 或 M7.2-a/b 数据。

## 计算链

1. 每个内部步在线性插值后的 M5A 相对笛卡尔位置上计算三颗恒星的方向、距离和
   `L/(4πr²)`，再结合归档或显式配置的自转轴、角速度和逐格法向量形成昼夜短波强迫。
2. 等面积纬度×均匀经度网格分别保存地表、浅层岩石、海洋混合层和近地空气温度。
   储层交换成对记账，闭合球面水平热/水交换全局和为零。
3. 五类表层物质先验有版本化固相线、液相线和潜热。硅酸盐液相才报告为岩浆；金属、含硫
   液相和水不冒充岩浆。水显式区分冰、液水、蒸汽、云水、径流及超临界不确定代理。
4. 大气柱从严格气体库存或归档的 G2/M7.1 大气先验初始化。压强由 `g × 柱质量` 得到；
   密度和平均摩尔质量只在气相适用范围内报告。温室反馈是有界灰体参数化。
5. 蒸发/升华、凝结、雨雪和径流与潜热耦合；风由温压梯度、自转和摩擦松弛参数化并受
   0.3 倍局地声速数值上限约束。天气事件使用进入/退出迟滞、持续时间和冷却时间。

## 物理计算、参数化和视觉层

| 层级 | 内容 |
| --- | --- |
| 物理计算 | M5A 牛顿轨道来源、逆平方辐照几何、显热/潜热预算、柱质量压强、库存守恒 |
| 参数化近似 | 灰体温室、水平扩散、地表交换、云降水时间尺度、摩擦/科氏风、事件阈值 |
| 纯视觉 | Web 色标、Canvas 地图、播放速度和瓦片显示降采样；不写回科学归档 |

模型不是全球环流、逐线辐射、云微物理、板块构造、岩浆流体、光化学或天气预报。轨道采样
之间的线性位置插值不能恢复未解析的近距离辐照尖峰；API 会保留相应不确定性标志。

## 归档与恢复

环境根目录包含解析配置、M5A 来源合同、根 manifest 和不可变段。每段保存状态快照、事件、
完整检查点及文件 SHA-256；检查点链包含前序哈希、累计外部能量、全部库存、风和事件计时器。
恢复前重新验证世界/运行身份、配置、运行时版本、M5A 段链和所有已提交环境文件。损坏、
篡改、符号链接、跨世界或配置不一致均拒绝。

## 查询语义

- `point`：数值字段在相邻已提交时刻线性插值，类别字段取最近时刻并返回来源括号。
- `series`：从同一归档做端点保留的有界索引采样，并返回归档天气事件。
- `tiles`：level 0 为原网格；更高 level 仅做已标识的算术显示聚合，不重新计算物理。

三类响应都包含模型、配置、M5A 来源和结果哈希、覆盖范围、SI单位及字段质量。
