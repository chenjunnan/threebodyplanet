# P0-M7.2-b～d 动态热环境实施规格

日期：2026-11-20。状态：M7.2-b 已合并，M7.2-c/d 已由
`integrated_environment_v1` 实现并等待集成复审。M7.2-a 的
`m72_three_reservoir_v1 / 0.8.0` 保持冻结，本规格新增模型而不改变旧归档。

## 1. 目标与阶段

M7.2 将零维三储热基准逐步扩展为可供游戏客户端查询、但仍可验证的动态环境：

1. **M7.2-b（已合并）**：一维等面积多纬带，三储层与守恒经向输送。
2. **M7.2-c（本集成分支已实现）**：经纬二维温度、昼夜/季节强迫和旋转相位。
3. **M7.2-d（本集成分支已实现）**：相变潜热、有限库存、长期分段与安全恢复。

统一实现契约、冻结数值门限和实际五年结果以
`docs/P0-M72_M73_INTEGRATED_IMPLEMENTATION_SPEC.md` 与
`docs/development/M72_M73_REPORT.md` 为准；本文件保留分层设计和旧模型边界。

M3/C1 继续作为独立科学基准，M7.2-a 继续作为零维解析/数值基准。任何新结果写入新的
模型 ID、schema 和派生目录，不覆盖 `environments/`、M5A 轨道或旧检查点。

## 2. M7.2-b 第一增量契约

- schema：`0.9.0`；模型：`m72_zonal_three_reservoir_v1`。
- 纬带在 `sin(latitude)` 上等距，因此每带面积相同，边界包含两极。
- 每带包含地表、浅层岩石和可选海洋混合层；全局库存按面积比例分配。
- M5A/基准强迫当前提供全局平均吸收通量。默认纬向权重与 `cos(latitude)` 成比例并严格
  归一化到等面积平均1；也允许显式非负、平均为1的权重用于基准。
- 带间接口热功率 `P(i→i+1)=K cos(phi_edge)(T_i-T_(i+1))`，相邻带取相反符号，
  因而全局和严格为零。`K` 单位为 `W/K`，不得与 `W/m²/K` 混用。

每带地表方程：

```text
C_s,i dT_s,i/dt = A_i(F_abs,i + F_internal - epsilon*sigma*T_s,i^4
                       - F_sr,i - F_so,i) + P_transport,i
C_r,i dT_r,i/dt = A_i F_sr,i
C_o,i dT_o,i/dt = A_i F_so,i
```

全局能量：

```text
d(sum_i(C_s,i*T_s,i + C_r,i*T_r,i + C_o,i*T_o,i))/dt
  = sum_i A_i(F_abs,i + F_internal - epsilon*sigma*T_s,i^4)
```

求解器额外积分右侧外部能量，直接报告残差；经向输送和储层交换必须抵消。

## 3. 行星物质组成与第一轮熔融诊断

`seeded_planet_material_prior_v1` 使用独立 PCG64 子流生成玄武质硅酸盐、花岗质硅酸盐、
铁镍、含硫物质和水冰五类主要表层物质质量分数。它是宽分布随机先验，不是行星组成观测，
也不改变 N 体质量。

第一轮对每种物质提供1 atm固相线/液相线和显式压力斜率，带温度在两者之间时用线性区间
作为未解析成分异质性的“液化概率”；混合物结果分别报告质量加权总液态期望分数和仅由
玄武质/花岗质硅酸盐贡献的岩浆期望分数，避免把液态水误称为岩浆。超过任一固相线后可出现
`PARTIALLY_LIQUID`，高总液态分数为 `LIQUID_DOMINANT`。该诊断：

- 不包含潜热、熔体迁移、对流、挥发、反应或地形重塑；不会反馈 M7.2-b 温度。
- 压力是显式固定边界，不是 M7.2-b 预测值。
- 高于简化凝聚相适用温度必须增加不确定标志。
- M7.2-d 才能在能量方程中加入潜热和守恒相库存；水相使用 IAPWS 边界，硅酸盐熔融需
  升级为压力、含水量和成分相关参数化。

岩石熔融参数化的后续校准参考 Katz、Spiegelman 与 Langmuir (2003)：
<https://agupubs.onlinelibrary.wiley.com/doi/full/10.1029/2002GC000433>。当前系数仅是版本化
游戏前置先验，不能声称复制该论文的地幔橄榄岩模型。

## 4. 稳定环境查询契约 v1

Python DTO `EnvironmentPointQuery` / `EnvironmentPointState` 是后续 HTTP API 的语言无关原型：

- 请求：SI物理时间、纬度、经度。
- 响应：模型 ID、结果 SHA-256、时间括号、插值方法、纬带、表面/岩石/海洋温度、固定参考
  压强、期望总液态/岩浆分数，以及预留的气温、湿度、风、降水和事件字段。
- M7.2-b 经度没有分辨率，必须返回 `ZONAL_MEAN_LONGITUDE_UNRESOLVED`。
- 未计算的大气/天气字段必须为 `null`，并包含 `NOT_COMPUTED` 不确定标志，禁止填零。
- 只允许在结果覆盖内查询；时间线性插值必须显式标识，不能制造新轨道采样。

M7.2-b-02 将在不可变归档和检查点落地后增加：

```text
GET /api/v1/environment/{run_id}/point?t_s=&latitude_deg=&longitude_deg=
GET /api/v1/environment/{run_id}/series?...&max_points=
GET /api/v1/environment/{run_id}/tiles/{time_index}/{level}
```

所有响应必须携带模型/配置/来源/结果哈希、SI单位和质量标志。Babylon.js/Three.js 只能读取，
显示帧率不改变权威物理时间。

## 5. M7.2-c 二维温度

- 使用等面积或明确面积权重的经纬网格；极区不得用零面积普通经纬单元。
- M5A恒星方向、自转轴/角速度和有限星盘形成逐格短波强迫，显式处理昼夜与季节。
- 水平热输送使用成对反对称界面通量，闭合球面总和为零；参数化扩散不得称为风。
- 进行纬向、经向和时间分辨率收敛；与 M7.2-b 面积平均、M7.2-a 全局平均交叉验证。

## 6. M7.2-d 相变与长期计算

- 温度跨越相边界时同时积分显热、潜热和固/液/气库存；每种物质库存非负且总质量闭合。
- 水相以 IAPWS 发布为参考：<https://www.iapws.org/relguide/IAPWS-95.html>；超出有效范围
  返回不确定/不适用，不外推为可信海洋。
- 岩石/金属熔融使用成分与压力相关固相线/液相线；未知成分不得产生精确岩浆比例。
- 长期运行复用 M5A 分段思想：不可变段、统一物理时钟、来源哈希、检查点链和恢复一致性。
- 轨道强迫采样无法解析的近接峰值必须报告时间分辨率风险。

## 7. 数值与验收门禁

M7.2-b 第一增量必须验证：

1. 均匀强迫解析平衡保持不变。
2. 等面积权重与纬向强迫全局平均严格闭合。
3. 储层交换和带间输送全局抵消。
4. 增大输送系数降低纬向温差但不创造能量。
5. 减小时间步结果收敛，全部温度有限且大于零。
6. 物质先验同 seed 可复现、不同 seed 独立、分数和为1。
7. 熔融分数随温度单调；压力修正与适用性标志可测试。
8. 查询哈希/覆盖/插值/未计算字段语义严格。
9. M7.2-a、M3/C1、M5A 与现有 Web 测试不回归。

纬向能量平衡模型的科学层级参考 North、Cahalan 与 Coakley (1981)：
<https://doi.org/10.1029/RG019i001p00091>。本实现是可验证的低阶模型，不是 GCM。
