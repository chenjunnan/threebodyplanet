# 三体星总体路线图

更新：2026-11-20。本文件接替历史 M0/M1 与 M5 计划作为整体状态入口。
“实现”与“科学适用性验证”“用户合并”是不同状态，不自动合并 PR。

## 产品目标

用真实四体轨道驱动单用户实验台；在可追溯的轨道和辐射之上，允许独立参数化行星探索。
科学归档、参数实验与视觉演示分层，不能由材质推断地形真实性、由质量推断氧气或把
条件灾害概率当成实测预报。碰撞后未知物理仍不计算。

## P1 前仍不承诺的科学能力

1. 内部演化：年龄、放射性元素、热容量、对流、潮汐、冷却历史，及独立数据/解析解校验。
2. M7.3 只做游戏需求驱动的简化柱模型和有界天气；逐线辐射、完整化学、逃逸与全球大气
   动力学不是 P0 完成前提。
3. 风场在 M7.3 通过守恒约束、压强梯度尺度和松弛/扩散参数化；除非未来实现并验证动力核，
   不得称为全球环流或天气预报。
4. 地形/风险：构造历史、岩性、板块、侵蚀与校准事件率；没有这些输入，不升级为灾害预报。
5. 渲染：高分辨率局部细节、真实照明/散射、地形遮挡、远近层级、多设备性能与可访问性。
6. 多人、生命文明、真实碰撞后流体与残骸：独立立项，不隐含于本次参数实验。

# P1 顺序调整（2026-11）

P1 以已合并的 M7.2/M7.3 集成归档为基线，依赖链为
`M5A 轨道 → M7.2 动态环境 → M7.3 参数化天气 → P1 只读游戏适配器`。
客户端采用 Babylon.js、TypeScript 与 Vite；Three.js 仅用于同场景选型基准。
P1 保留科学控制台且不修改或覆盖历史科学归档。
