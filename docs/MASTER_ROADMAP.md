# 三体星总体路线图

更新：2026-11-17。本文件接替历史 M0/M1 与 M5 计划作为整体状态入口。
“实现”与“科学适用性验证”“用户合并”是不同状态，不自动合并 PR。

## 产品目标

用真实四体轨道驱动单用户实验台；在可追溯的轨道和辐射之上，允许独立参数化行星探索。
科学归档、参数实验与视觉演示分层，不能由材质推断地形真实性、由质量推断氧气或把
条件灾害概率当成实测预报。碰撞后未知物理仍不计算。

## 后续科学升级（尚未实现）

1. 内部演化：年龄、放射性元素、热容量、对流、潮汐、冷却历史，及独立数据/解析解校验。
2. 大气：成分化辐射输运、挥发/逃逸、凝结和水库存交换；光学厚度不能长期当作自由参数替代这些机制。
3. 气候：有边界条件的能量/质量/动量方程、地表摩擦和经向输送，替代单一地转风尺度。
4. 地形/风险：构造历史、岩性、板块、侵蚀与校准事件率；没有这些输入，不升级为灾害预报。
5. 渲染：高分辨率局部细节、真实照明/散射、地形遮挡、远近层级、多设备性能与可访问性。
6. 多人、生命文明、真实碰撞后流体与残骸：独立立项，不隐含于本次参数实验。
