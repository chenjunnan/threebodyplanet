# P0-M7.1 基线、随机行星与地面观测实施规格

## 1. 科学语义

M5A 已提交轨道、初态质量/半径/自转与恒星光度是权威归档量。M7.1 可以在其上计算
明确公式的参考量，也可以生成带种子和分布版本的参数先验，但二者必须在结果中分开。

- 大气存在是 `retention_weighted_prior_v1` 的随机假设，不是由质量或自转证明的事实。
- 纬向风输出是受热力/地转参考尺度约束的可复现范围，不是局地天气或风场预报。
- 可见光大气颜色采用三波段 Rayleigh/吸收代理，不是逐线光谱辐射输运。
- 画面亮度采用实际计算的地表直达辐照比例，再经 HDR 色调映射显示；屏幕像素不是 SI 亮度计。
- 地形为可复现程序场，不是构造、侵蚀或测绘结果。

## 2. M7.1-01 基线收口

更新当前授权、路线图、合并状态和包版本；保留归档 schema 各自版本。浏览器 E2E 与 M7
数值验收必须在相关 PR 和相关 main push 后运行。Python 3.11/3.12 通用 CI 保持不变。

## 3. M7.1-02 Web 核心层

提供单一 `ThreeBodyWeb` 核心，统一 JSON 请求、共享状态和路由进入/离开通知。现有页面可渐进
迁移，不引入公共服务器、数据库或前端框架；服务端物理时间仍为唯一权威时间。

## 4. M7.1-03 随机行星契约

新增 `stochastic_conics/0.4.3`。0.4.2 与旧版本输出逐字节兼容。新版本至少包含：

- 行星自转周期的 SI 秒分布与各向同性自转轴；独立随机流不得扰动轨道抽样。
- 大气先验发生率、质量分数分布与成分 Dirichlet 参数。
- 使用质量、半径、自转、当前三恒星辐照形成有效逃逸速度与 Jeans 参数诊断。
- 归档随机抽样、判断阈值、组成、质量和模型 ID；无大气时各气体库存为零。

## 5. M7.1-04 纬向风范围

有大气时，每个纬带计算热力参考速度；远离赤道且 Coriolis 有效时同时计算地转参考尺度。
使用场景种子的独立子流抽取范围系数，输出上下界和适用语义；上界受局地声速比例限制。
真空返回 `null`，不能静默生成风。

## 6. M7.1-05 地形与等高线

地形保持连续、种子可复现、绝对起伏小于半径 5%。增加多尺度山脊，使默认起伏可见；全球
地图绘制 24 个等间隔高程级别的等高线，界面不得暗示其为真实地形。

## 7. M7.1-06 地面回放和大气光学

地面镜头只请求/显示时间轴上精确已提交的轨道采样。播放可以随统一物理时间更新天空，并可
锁定某颗当前在地平线上的恒星。服务端按观测高度、气压和成分计算三波段光学厚度、天空颜色
代理、空气质量与各恒星地表直达辐照；地平线下直达辐照为零。WebGL 使用这些量做相对照明和
色调映射，不外推轨迹，不伪造云、折射或多次散射。

## 8. 验收

1. 旧 0.4.2 固定种子回归不变；0.4.3 同种子可复现且不同候选具有自转/大气多样性。
2. 逃逸/Jeans、组分和质量守恒、风速上界、真空、天顶/地平线消光均有单元测试。
3. 地形连续/有界，地图恰有 20–30 个配置等高线级别。
4. Chromium 验证轨迹播放、恒星锁定、天空颜色和参数失效处理。
5. `pytest -q`、`ruff check .`、`compileall`、JavaScript 语法和 wheel 构建通过。
