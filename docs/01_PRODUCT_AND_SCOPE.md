# 01 — 产品背景、P0边界和科学声明

## 1. 项目背景

《三体星》是一款由真实天体力学及行星环境演变驱动的3D模拟游戏。世界包含三颗互相引力作用的恒星与一颗真实物理尺寸的岩质行星。未来由权威服务器持续演进，Web客户端负责呈现。未来阶段考虑气候、海洋、第三人称观察、多人、生命和文明。

本包专门为 **P0-M0/M1**：可复现的四天体初态与可配置初始筛选。后续 M2 调用真实引力积分器；M3 引入辐射与热模型。

## 2. 已批准决策

- 使用真实物理计算，但通过独立可配置的筛选选择适合探索的候选世界。
- Web优先，暂不开发Web游戏本体。
- 行星半径等物理尺寸真实，地表开放范围后续局部精细化。
- 在线高精度、离线自适应演进是远期服务端目标，M0/M1只保存可扩展数据契约。
- 初始物理合法性检查作为可配置项目，规则可单独打开/关闭、调整阈值和版本。

## 3. 里程碑表

| 里程碑 | 本包代码范围 | 验收性质 |

| M0 | 工程、模型、配置Schema、单位、序列化、CLI | 必做 |

## 4. 科学边界与命名

- 三颗恒星加一颗行星构成四体问题。P0-M1不计算演化，因此不能生成“轨道稳定性证明”。
- `physical validity` 包含模型适用性；`exploration suitability` 包含目标世界偏好，二者不能混同。
- 不允许把简单半径+密度范围规则宣称为精确行星内部结构模型。
- `hierarchical_orbit` 是*构造初始条件*的手段；近似两体分层初始化，不保证复杂系统的长期束缚。
- 当用户关闭规则，候选仍可进入结果集，但必须标注哪些规则未评估及科学有效性不确定。

## 5. 第一阶段交付给用户

- 可安装且有可复现示例的Python CLI。
- 三种可配置筛选预置和一个完整示例配置。
- JSON初态、筛选报告、配置快照、统计汇总。
- 单测和集成测试。`pytest -q`通过。
- 未来对接真实天体积分器的清晰边界文档。
