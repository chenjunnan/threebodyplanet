## 地表观察修正

- `planet-exploration-v3` 首次固定十级等高线并在全球地图绘制当前观测位置；水库存与透视
  语义升级为 v4，本轮环境地貌契约进一步升级为 `planet-exploration-v5`。
- 海平面改由同一连续地形的 192x384 等面积网格求解，输出库存体积残差；地图与地面视角
  统一按海平面判断盆地水体。
- 地面恒星按半径/距离得到的角半径与当前视场换算屏幕直径；完全消光的恒星不再画成黑盘。
  厚大气且散射明亮时隐藏装饰背景星。
- 默认四倍地形垂直夸张只存在于显示路径，返回值明确标记
  `DISPLAY_ONLY_NOT_USED_BY_PHYSICS`。
- 新增 `environment_morphology_proxy_v1`：固定初始构型参考温度与稳定的大气、自转、水库存
  参数形成侵蚀/断裂先验，确定性生成大平原、山脊、断裂峡谷和陡坎。地图、水盆和WebGL
  使用同一高度函数；该模型明确不是板块构造反演，播放时不会重塑地貌。
- WebGL显示夸张现在同步作用于坡面法线，水面保持水平法线；高程色调和大气同色远景雾增强
  地面深度线索，但不改变任何科学海拔。

## 已知限制

- 单区域模型没有纬向/经向温差、相变潜热、云、海洋环流或大气动力学。
- 储层质量、比热和换热系数是显式参数化近似；M7.2-a 不演化物质库存。
- M5A 输出之间的近接辐照峰值无法由线性标量插值证明或重建。
- JSON 检查点不保存 SciPy 内部 RK 阶段，恢复按固定容差一致而非逐位一致。
- CI 暴露了旧 0.4.2 全精度 JSON 哈希会随受支持 Linux runner 的 `libm` 末位变化。
  回归现在同时要求同一已记录运行时内逐值精确重放，并以 12 位有效数字冻结跨平台科学值。
  该兼容修正不改变生成器代码或旧归档，也不把平台末位差异误报为新的物理世界。

## 同名运行派生归档修复

实际 `my-world-003` 暴露出同名 M5A 目录被外部移除并重建后，旧 M4 目录仍指向前一个
世界的问题。来源校验正确拒绝了它，但重试无法自行恢复。流水线现在只对格式可识别且
M5A 来源合同明确不匹配的旧环境、热检查点或 M4 目录执行原子隔离，保存在
`stale_derived/<run_id>/`，随后为当前权威轨道重新计算；未知格式和损坏文件仍然硬失败。
新任务创建也会拒绝复用仍有派生数据的 `run_id`，从入口阻止再次发生。

## 亚像素恒星方块修复

`my-world-003` 在 `t=22377600 s` 暴露出不可解析恒星被强制成 2×2 点精灵后呈现方块，
同时恒星锁定使用了错误的旋转分支，会把高高度角目标转到相机后方并在画布顶边留下裁剪块。
现在亚像素恒星使用 5 px 抗锯齿点扩散显示代理，可解析恒星仍按真实角直径画圆盘；锁定旋转
明确保持目标位于相机 `-Z` 前方。点扩散下限属于纯视觉参数，不改变角直径、位置或辐照。

`my-world-021` 进一步暴露出高仰角、8–26°大视直径恒星下，旧的常量远平面会让跨相机平面的
地形三角形覆盖天空。地形现使用有限近/远平面的标准透视深度；80°锁定像素回归验证顶部与
角落保持同一连续天空色，恒星圆盘位于画面中心且方向不翻转。

场景契约升级为 `planet-exploration-v4`。水库存使用全球等面积温度、冰面升华压力和IAPWS液面
饱和压力代理，守恒地分配到地表和大气；局地相态由温度与水蒸气分压共同判断，干燥背景气体
的总压不会被误当成水分压，局地673 K不再显示液态水。全球温度超过647.096 K时地表库存全部
进入大气，并按22.064 MPa临界压力区分蒸汽与超临界含水包层。该模型是瞬时全局平衡近似，
不声称模拟云、降水、环流或冷阱输运。

地表观察器的近裁剪面现在按观察高度自适应。地形坐标以100 km为单位时，默认2 m观察高度的
近裁剪距离为0.5 m，而不是旧实现约200 m；浏览器像素回归同时验证前景地面、连续天空和高仰角
恒星锁定，防止地面再次被裁成整块天空色。
