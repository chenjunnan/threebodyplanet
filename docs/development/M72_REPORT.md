# P0-M7.2-a 开发报告

日期：2026-11-18。分支：`feature/p0-m72-dynamic-environment`。

## 实现

- 新增严格的 `m72_three_reservoir_v1 / 0.8.0` 环境契约：地表、浅层岩石、海洋混合层的
  温度、质量、比热、总热容量、瞬时通量和总显热全部使用 SI。
- 新增恒定辐射、阶跃辐射及只读 M5A 三恒星强迫。真实强迫验证完整分段链、初态哈希、
  规范天体顺序、光度、采样间隔和覆盖范围；采样间仅线性插值辐照标量。
- SciPy `solve_ivp` 同时积分三储层温度和外部净能量，报告守恒残差、温度范围与函数求值数。
  配置、来源和完整结果使用互相独立的 SHA-256。
- 新增不可覆盖、拒绝符号链接、带前序哈希和运行时/积分配置的 JSON 检查点；恢复严格校验
  配置与强迫来源，在检查点边界重启求解器。
- M3/C0/C1 代码、归档路径和 schema 未修改。

## 地表观察修正

- `planet-exploration-v3` 固定十级等高线并在全球地图绘制当前观测位置。
- 海平面改由同一连续地形的 96x192 等面积网格求解，输出库存体积残差；地图与地面视角
  统一按海平面判断盆地水体。
- 地面恒星按半径/距离得到的角半径与当前视场换算屏幕直径；完全消光的恒星不再画成黑盘。
  厚大气且散射明亮时隐藏装饰背景星。
- 默认四倍地形垂直夸张只存在于显示路径，返回值明确标记
  `DISPLAY_ONLY_NOT_USED_BY_PHYSICS`。

## 已知限制

- 单区域模型没有纬向/经向温差、相变潜热、云、海洋环流或大气动力学。
- 储层质量、比热和换热系数是显式参数化近似；M7.2-a 不演化物质库存。
- M5A 输出之间的近接辐照峰值无法由线性标量插值证明或重建。
- JSON 检查点不保存 SciPy 内部 RK 阶段，恢复按固定容差一致而非逐位一致。
