# P1 浏览器 3D 行星探索开发报告

状态：功能与本地软件渲染验收完成，等待 PR CI 与复审；未在独立显卡设备上宣称性能达标。

## 交付

- 生产客户端为 TypeScript、Vite、Babylon.js；`/game/` 与旧科学控制台并存。
- 游戏世界列表只接受身份匹配且 `COMPLETED` 的 M5A 与 M7.2/M7.3 归档。
- 新游戏场景适配器从严格验证的环境 `resolved_config.json` 读取世界种子、自转轴、
  自转速率、大气柱、水库存与气体先验；M5A/环境时间取共同覆盖且禁止外推。
- 81 个动态球面分块：中心 5×5 个 4 km LOD 12 块形成连续 20×20 km 区域，外围
  LOD 11；Cube-Sphere 面/四叉树键、共享边采样、球面曲率和 1.5 km 浮动原点。
- 参数化地形包含山体、平原、断层/峡谷、海岸及按海平面填充的水面。它不是地质观测。
- 第一/第三人称、WASD、奔跑、跳跃、权威 `g` 值、地形高度碰撞、重置和画质档位。
- 三星方向来自 M5A 插值显示轨迹，盘面直径为 `2 asin(R/d)`；姿态使用归档自转轴、
  转速和物理时间。辐照度经显式曝光映射，大气削弱为按气压/成分/气团质量的标量代理。
- M7.3 驱动云层、雾、雨、雪和风漂移；粒子位置随机性仅为视觉，不决定天气状态。
- M7.2 驱动液水、冰、部分熔融/岩浆材质；质量标记为不确定时 HUD 明示。
- 全球参数化地形图、局部 LOD 指示、位置、海拔、三星、时间、环境和事件 HUD。
- 玩家存档绑定 run ID 与 M5A 初态 SHA-256；来源变化时拒绝旧存档。

## 引擎与性能实测

双引擎同场景结果见 `P1_ENGINE_SELECTION.md`。生产 P1 真实归档场景在 Chromium
WebGL2 + SwiftShader、1280×800、81 个地形块中测得：

| 指标 | 实测 |
| --- | ---: |
| 游戏初始化就绪 | 571.9 ms |
| 首个渲染帧 | 210.5 ms |
| 稳定帧时 P50 / P95 | 16.70 / 17.10 ms |
| 地形销毁重建 P95 | 21.60 ms |
| JS heap | 16.31 MiB |
| 首次传输 | 2.08 MiB |

这是 CI 软件渲染数据，只证明 WebGL2 基础路径和本场景帧调度；不等同于独立显卡、
移动 GPU、总进程内存或 GPU 显存结果。正式硬件矩阵仍应在复审时补测。

## 科学和工程限制

- M5A 样本之间仅作客户端线性显示插值，不重新积分，不在覆盖外推。
- 大气消光是宽带单路径参数化，不是逐线光谱、多次散射或屏幕绝对亮度标定。
- 地形为可复现形态代理；无板块构造、侵蚀历史、洞穴和悬挑，碰撞是单值高度场。
- 云雨雪是权威强度/相态驱动的视觉代理，不是客户端大气动力学。
- 岩浆只有归档熔融状态的材质和发光表现，无流体、地形重塑或板块模拟。
- 角色使用占位胶囊，无正式美术、骨骼动画、建造、多人或 P1 后续玩法。
