## 本轮交付

- 七个独立路由工作区，一次只显示一个；共享真实归档/时间选择，返回切页不丢当前采样，启动模拟转到任务页。
- 星空装饰背景、桌面/390px移动布局。隐藏环境页不执行图表重绘；Canvas轨迹缓存历史位图并增量追加，倒放/换相机/换窗口会重建。
- 严格只读参数 API，精确已提交采样、源哈希、自转参数与运行/世界校验；碰撞时刻起禁止地表场景。
- 球形重力、离心修正参考值、库存静水压力/等温尺度高度、氧/水汽分压、内核导热和灰色辐射平衡、纬度/赤道/两极温度、有限适用地转风尺度。
- 可复现连续球面地形与山地/水盆、离散水量守恒、粗略水相。地形模态随结果导出，区域为24×48等面积单元，显示图用连续地形细化。
- WebGL地表镜头：近密远疏网格、程序材质、三源方向参考照明、视角/缩放/键盘、显式眼高、真实恒星几何方位/高度。经度初相位为用户假设。
- 区域发生率+明确事件定义+时间窗→平稳泊松条件概率；没有输入率时未知，不提供伪造的地震/火山预测。
- 场景JSON导出包括模型/运行时版本、源与参数哈希、地形模态、假设及结果。修改参数、采样或运行会清空旧场景；过期异步结果不覆盖新场景。
- 新OpenAPI端点/参数schema、数值验收脚本与独立CI工作流；更新总体路线图、历史状态提示、README与模型说明。

## 真实科学重跑

原始结果在 `docs/acceptance/m7/`，没有人工构造轨迹或温度：

1. 五年IAS15→M3/C0/C1→M4→热检查点复用：7306点、6小时采样。
   IAS15 7.682秒，科学派生69.457秒，检查点复用4.479秒；峰值275.76 MiB。
   C0/C1归一化能量残差约1.44e-15 / 2.83e-16。
2. 30天宽恒星受控构型与紧凑三恒星构型，各运行6h/3h采样，以及3h采样下IAS15
   epsilon=1e-9/1e-12对照。守恒缩放误差约4.28e-16 / 5.61e-16；
   C0末值差约1.1e-11 K，C1末值最大差约4.1e-9 / 5.2e-9 K。
   两种容差未出现可分辨的末位置差异；不能据此推断其他构型、任意时长或更强混沌均收敛。
   比较温度门限0.5 K、容差对照位置门限1e-8 AU在脚本中预先固定，未因结果放宽。

该紧凑构型不是已测量的Lyapunov混沌分类；没有宣称一般长期稳定/宜居。
第一次数值夹具修改世界ID触发了既有S0命名约束，已保留规范ID并用独立生成器/配置哈希
标识夹具后重跑；没有禁用校验或修改积分器。

## 观察器性能

记录：`docs/benchmarks/m7-workspace-observer-final-2026-11-17.json`。
相同机器软件WebGL2、4天体/2000点、每模式120帧，预热10帧：

| 模式 | 绘制p95(ms) | 帧间隔中位数 / p95(ms) |
| --- | ---: | ---: |
| Canvas静态 | 0.4 | 33.3 / 50.0 |
| Canvas回放 | 0.7 | 33.3 / 50.0 |
| WebGL静态 | 0.3 | 16.7 / 50.0 |
| WebGL回放 | 0.5 | 16.7 / 49.9 |
| WebGL聚焦回放 | 0.9 | 16.7 / 49.9 |

本轮缓存前测量也保留在不带final的同名报告中，Canvas中位数约83～100ms。
这是本机观测，不是无控制变量的通用速度保证。Canvas提交耗时不含完整光栅化，
WebGL绘制含gl.finish；帧间隔单独报告。仍有掉帧，不能承诺稳定60FPS。
此基准不包含地表场景生成、热面板、科学计算或API读取；未宣称全部页面都达到同等帧率。

## 已知边界与后续

这是可运行、可导出的**参数化探索版本**。尚未实现内部冷却历史、真实成分化大气、
完整天气/风场、板块与侵蚀历史、经校准的区域地质事件率、照片级地表、光谱散射与地形遮挡。
程序地表与示意照明不能当作真实地貌观测。尺度高度不是大气硬边界，地转尺度不是地表风预报。
后续科学升级/视觉质量与设备性能目标在总体路线图中明确保留，不以本次通过测试冒充完成。
