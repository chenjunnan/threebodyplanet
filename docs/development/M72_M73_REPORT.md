- 不可变环境段、完整连续状态检查点、前序哈希链、安全恢复、来源/配置/运行时验证及
  损坏、篡改、跨世界拒绝。
- 新增 `threebody world environment-long` CLI；新增 point、series、tiles 三个同源只读 API。
- Web 科学环境页新增温度、水/冰/熔融、压强、湿度、风、降水图层，物理时间播放、地点查询、
  天气事件和完整来源哈希显示；浏览器不生成或回填科学随机数。

## API 交付

```text
GET /api/v1/environment/{run_id}/point?t_s=&latitude_deg=&longitude_deg=
GET /api/v1/environment/{run_id}/series?latitude_deg=&longitude_deg=&start_s=&end_s=&max_points=
GET /api/v1/environment/{run_id}/tiles/{time_index}/{level}
```

客户端可直接依据响应中的 `coverage_s`、`grid_source`、SI单位、字段质量、插值方法、
`config_sha256`、`forcing_source_sha256` 和 `result_sha256` 做缓存与来源校验。瓦片只做显式显示
聚合，不重新求解；播放速度不改变服务端物理时间。

## 科学限制

- 轨道位置在 M5A采样之间线性插值，6小时采样不能恢复更短的近接辐照峰值。
- 温室是有界灰体代理；无逐线光谱、光化学、气溶胶、完整云微物理或大气逃逸。
- 风是压强/温度梯度、自转和摩擦的有界参数化，不是 Navier–Stokes/GCM 或天气预报。
- 岩石和超临界水物性是版本化宽范围代理；高于2500 K或超临界水明确为
  `UNAVAILABLE/UNCERTAIN`，不声称高精度岩浆或流体动力学。
- 无地形高度、海洋环流、侵蚀或板块构造耦合；Web 色标和播放是纯视觉层。
- 五年完成只证明该输入和窗口的计算完成，不证明长期轨道稳定、宜居性或真实观测一致性。
