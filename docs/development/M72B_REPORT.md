  时间括号、纬带、温度、固定参考压强和相态诊断；M7.2-b 未计算的气温、湿度、风、降水和
  天气事件严格返回 `null/空事件 + NOT_COMPUTED`，没有虚假占位数值。
- 真实 M5A 三星标量强迫可直接驱动新模型，且与 M7.2-a 使用相同强迫来源 SHA-256。

## 科学适用范围与已知限制

- 当前是纬向一维低阶能量平衡模型；没有经度、昼夜、季节、云、风或天气。默认 `cos(latitude)`
  权重只是归一化纬向强迫，不使用真实瞬时恒星方向；M7.2-c 才引入二维旋转强迫。
- 经向输送系数是显式参数，不是由大气/海洋动力学推导；只能解释为守恒热扩散代理。
- 随机物质是宽分布先验，不是行星形成、分异或光谱观测。其质量分数不修改 N 体行星质量。
- 第一轮相态诊断没有潜热、物质迁移、化学反应、挥发或地形反馈。固定压力不是预测值；
  线性固相线/液相线不能用于高压地幔定量结论。M7.2-d 必须用守恒库存和潜热替换反馈路径。
- 查询中的经度无分辨率；压强是边界条件；大气与天气字段为空。HTTP 点/序列/瓦片端点要等
  不可变 M7.2-b 归档与检查点完成后再实现，当前不会向 Web 暴露内存假状态。
- M7.2-a、M3/C1、M5A 归档和检查点格式没有改变。
