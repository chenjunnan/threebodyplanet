# P1 浏览器 3D 行星探索实施规格

状态：已实施，等待集成 PR 复审；模型边界在实现前固定。

生产引擎采用 Babylon.js，TypeScript/Vite 构建；Three.js 只存在于同场景评估入口。
科学控制台与 `/game/` 独立。

## 权威数据边界

- M5A 是天体位置、轨道覆盖时间和天体初态属性的唯一来源；不外推覆盖区间。
- M7.2/M7.3 环境归档是温度、压强、湿度、风、云、降水和相态的唯一来源。
- 程序地形严格复用 `planet-exploration-v9` 的种子、模式和连续高度函数。
- 缺失、损坏或来源哈希不匹配的数据标为 `UNAVAILABLE`，客户端不得补科学数值。

## 坐标与地形

科学坐标保留双精度 ECEF/惯性 SI 米。渲染坐标是玩家附近的局部 ENU 米制坐标；
浮动原点只改变显示变换。首个连续区域为 5×5 个 4 km 块，即 20×20 km。
块边界从同一球面连续函数采样，禁止块内独立噪声。

## 玩家与时间

重力使用归档 `G M/R²` 值并指向球心。角色支持 WASD、奔跑、跳跃和第一/第三人称。
存档绑定 run ID 与初态 SHA-256；哈希变化拒绝旧位置。播放速率不等于积分速率，
物理时间不得越过归档覆盖。

## 预先固定的验收阈值

- 地形公共边高度误差不超过 `1e-6 m`。
- 20 km 内 ECEF/局部坐标往返误差不超过 `1e-6 m`。
- 恒星角半径采用 `asin(R/d)`，单元基准相对误差 `1e-12`。
- 地面站立穿透不超过 `0.05 m`，跨块不得发生可见跳跃。
- WebGL2 Chromium E2E 无 page error；科学回归必须通过。
- 性能报告 P50/P95 帧时间、首次进入时间和内存；软件渲染不得代表桌面 GPU。

实际实现、性能环境与限制以 `docs/development/P1_REPORT.md` 和 PR 检查为准。
