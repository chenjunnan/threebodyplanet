# P1 引擎选型记录

同一 Chromium/SwiftShader 场景包含 16,641 个地形顶点、32,768 个三角形、三个方向光、
轨道相机、地形高度碰撞和同一个嵌入式 glTF。每个引擎预热 60 帧后采样 360 帧。

| 引擎 | 首帧 | 帧时 P50 / P95 | JS heap | 资源 | 页面错误 |
| --- | ---: | ---: | ---: | --- | --- |
| Babylon.js 9.37.1 | 94.0 ms | 16.70 / 16.80 ms | 28.04 MiB | 成功 | 0 |
| Three.js 0.187.0 | 64.6 ms | 33.30 / 33.40 ms | 29.75 MiB | 成功 | 0 |

选择 Babylon.js。它在本次软件渲染基准中更稳定，游戏抽象也更符合项目需求。该数据不能
代表独立显卡性能；Three.js 首帧更快也如实保留。原始结果在
`docs/development/P1_ENGINE_BENCHMARK.json`。评估页不形成第二套游戏。
