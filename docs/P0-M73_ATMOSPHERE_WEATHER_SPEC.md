# P0-M7.3 简化大气、水循环与基础天气实施规格

日期：2026-11-19。状态：设计提交，尚未实施完整天气系统。依赖 M7.2-d 的二维地表温度、
相变库存、长期检查点和稳定查询来源。

## 1. 产品目标与科学边界

M7.3 为 P1 游戏客户端提供连续、可追溯、有预算约束的环境状态，而不是把完整全球大气
动力学作为 P0 完成前提。必须提供气温、气压、湿度、风、降水和基础天气事件，但模型只能
标记为“简化大气柱/有界天气参数化”，不得称为真实天气预报或完整 GCM。

Held–Suarez 基准说明动力核与物理参数化需要独立验证；M7.3 不实现该级别动力核：
<https://www.gfdl.noaa.gov/bibliography/related_files/ih9401.pdf>。未来若引入浅水方程或原始方程，
必须新立模型 ID，并通过独立动力核基准。

## 2. 权威状态

每个网格柱和 SI 物理时刻至少记录：

- `surface_temperature_k`、`air_temperature_k`、`surface_pressure_pa`。
- 干空气各成分质量、`water_vapor_kg_m2`、`cloud_condensate_kg_m2`。
- 比湿、相对湿度和露点（可推导量，带方法 ID）。
- `eastward_wind_m_s`、`northward_wind_m_s`，以及风场来源/适用性。
- 蒸发、凝结、降水和径流通量 `kg/m²/s`。
- 地表液水/冰、海洋混合层水、积雪和大气水库存。
- 感热、潜热、短波、长波和水平输送能量通量 `W/m²`。
- 事件状态、开始/结束时刻、阈值、迟滞、持续时间与置信/不确定标志。

所有状态携带轨道、M7.2、配置、模型和前序段哈希。压强必须由柱质量与重力推导或明确是边界
输入；湿度、风和降水不能从画面颜色反推。

## 3. 分阶段实现

### M7.3-a：简化大气柱

- 干空气质量固定起步，水蒸气质量可变；表面压强由总柱质量乘重力计算。
- 地表—近地空气采用有界感热交换；长波使用明确灰体/三宽带参数化。
- 饱和比湿由温度和水分压计算；超出相图/稀薄或高压适用范围返回不确定。
- 风先采用压强梯度/温度梯度参考尺度加阻尼松弛，并受声速/能量上限约束；不求完整动量方程。

### M7.3-b：守恒水循环

- 蒸发受可用地表水、净能量和空气未饱和度共同限制。
- 饱和调整把超饱和水蒸气转为云凝结物并释放潜热。
- 云水超过显式阈值后按时间尺度降水；降水进入地表液水/冰或径流库存。
- 每步验证“大气水 + 云水 + 地表水/冰 + 累计流出”的质量闭合；不得创建负库存。
- 水/蒸汽热力性质采用 IAPWS 有效范围，盐度、非理想混合物和复杂云微物理标记未实现。

### M7.3-c：基础天气事件

- 晴朗、云层、降雨、降雪、强风、热浪/寒潮、雾和雷暴候选等事件由连续状态阈值产生。
- 每种事件必须有进入/退出不同阈值、最短持续时间和冷却时间，避免逐帧闪烁。
- 雷暴等缺少垂直对流解析量时只能输出候选/低置信标签，不能断言发生。
- 随机扰动使用 `(world seed, model version, cell id, physical step index, stream id)` 独立子流；
  改变渲染帧率、查询顺序或筛选不得改变天气历史。

## 4. 连续性、预算与稳定性

- 温度、压强、库存和风状态按物理时间连续积分；离散事件是连续状态的带迟滞分类。
- 全局水质量相对残差和总能量残差均需报告绝对值与缩放值。
- 潜热在地表/空气/云相变双方以相反符号记账。
- 水平交换采用成对反对称通量；闭合球面净质量/能量输送为零。
- 风速限制不是静默钳位：达到稳定性上限必须记录数值安全事件和不确定标志。
- 至少验证时间步、空间分辨率、分段恢复和长时间平衡/周期强迫收敛。

## 5. 环境时空查询 API

稳定响应沿用 `environment-point-state-v1`，逐步把 M7.2-b 中的 `null` 字段替换为真正 M7.3
计算值。字段含义和单位不变，模型 ID/质量标志说明其来源。API 分三类：

1. `point`：单时刻单位置，允许显式的时间/空间插值。
2. `series`：同一位置的有界降采样时间序列，返回所保留的极值和事件边界。
3. `tiles`：客户端 LOD 网格；瓦片只降采样权威场，不重新求解物理。

响应统一包含：覆盖范围、物理时间、坐标/网格语义、SI单位、源括号、插值方法、所有来源
SHA-256、字段级 `quality=COMPUTED|PARAMETERIZED|UNCERTAIN|NOT_AVAILABLE`。未知值为 `null`，
不能用0、随机数或上一个有效值静默填充。HTTP缓存键必须包含结果哈希和查询参数。

## 6. 测试与适用范围报告

- 静止饱和柱、干柱、恒定辐射和辐射阶跃基准。
- 单格蒸发—凝结—降水水质量闭合，潜热能量闭合。
- 两格压强/温度梯度的有界风响应及交换反对称性。
- 周期强迫下连续温湿度和事件迟滞，不随查询/帧率改变。
- 高温蒸汽、低压稀薄大气、冻结和无水场景返回正确适用性标志。
- 检查点恢复与不中断运行一致；API 点/序列/瓦片来源一致。
- 每个增量生成独立科学适用范围报告，列出参数化、未解析过程和数值稳定范围。

## 7. 明确排除

M7.3 不以逐线辐射、完整光化学、气溶胶微物理、三维对流、全球原始方程动力核、海洋环流、
长期大气逃逸或真实灾害预测为完成条件。轻量引擎只能读取 API 做坐标、材质和性能预研；
正式 P1 角色、地形资产和玩法不得在本阶段启动。
